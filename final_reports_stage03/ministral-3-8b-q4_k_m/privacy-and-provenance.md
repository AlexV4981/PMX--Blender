# Privacy and provenance

This package is assembled from explicit text/numeric allowlists and verified local evidence. It is a public analysis export, not a complete raw experiment backup.

Exact synthetic prompts and settings are included; all twenty reconstructed prompt hashes per lap were checked against the ledger. Real prompts use the already published Qwen identifier-redacted base plus the exact safe operator-authored additions. Character/object identifiers and custom material identifiers remain replaced with placeholders. Real prompt hashes refer only to this public redacted text; full reproduction requires privately held licensed assets and evidence.

Excluded: personal and machine identifiers, absolute local/network paths, credentials, continuation-token arrays, native Modelfile, raw logs, model-generated source and reasoning, private scenes/textures/motions, original asset and contract fingerprints, unreleased reference implementation, and results outside Stage03. Generic Blender API names and already published aggregate mesh counts are retained for interpretation. Synthetic code hashes identify synthetic outputs only; original real candidate and asset hashes are not published.

The underlying ledger/artifacts, frozen requests and model/source integrity checks were reviewed locally. Public checksums establish export consistency, not independent execution attestation. The report is operator-authored; original model completions have not been rewritten into successful answers or rerun under earlier identifiers.
