# Premade animation assets

This directory stores the **manifest**, not the copyrighted animation binaries. The user requested that PMX and Blender animation resources remain available. The original source links and provenance are preserved here and in [PREMADE_ANIMATION_PACKS.md](../../PREMADE_ANIMATION_PACKS.md); no download has been performed or verified. After confirming licenses, place source files in ignored `../data/animation-assets/pmx-vmd/` and `../data/animation-assets/blender-native/`. Preserve source archives unchanged, record SHA256, and create retargeted copies separately. Do not commit unlicensed binary animations. If long-term repository-hosted binary assets are desired, use Git LFS or a separate rights-cleared release and update hashes/URLs; GitHub source branch alone does not guarantee binary retention.
