# Stage 05 Qwen3.5-0.8B weight trial: three failed morph-inventory responses

Three matched Hugging Face inferences failed one bounded, read-only Blender source-morph inventory. Neither experimental weight edit was promoted. The user accepted the preceding native rig for stage 05, but this test did not create face controls or complete stage 05.

## Controlled comparison

The source was `Qwen/Qwen3.5-0.8B` at revision `2fc06364715b967f1860aea9cf38778875588b17`, with original safetensors SHA-256 `04b1c301231dd422b8860db31311ab2721511346a32cb1e079c4c4e5f1fe4696`. Both variants were fresh clones of this source; its hash remained unchanged. All three runs used the same case hash `e43fd76e8ac77ee7bcc79113d817c911520c9207a87486facd9be6c59e816db8`, runner hash `182c51586ae6043084322aff403693f52f365447ccf26a1afdba149a2ecd0581`, 332 input tokens, CPU BF16/eager attention, eight threads, greedy decoding, thinking disabled, seed 0, and a 1,536-new-token cap. This is an HF-to-HF comparison, not a comparison with the separate Ollama GGUF.

The case supplied the character mesh name and ten observed source shape-key names. It requested JSON containing read-only `bpy` code that reports whether each key exists, its slider range, current value and relative key. The accepted predecessor had 146 shape keys, including Basis; the ten sampled keys were independently observed to exist, with slider ranges 0–1 and Basis as their relative key. The generated code was never executed. Lynae was evaluation-only; neither user assets nor Codex-authored solutions or model responses were used as training labels. Raw prompts, outputs, assets and weights remain in the ignored local lab.

The two edits covered input and post-attention RMSNorm vectors across all 24 decoder layers. Each changed 49,152 of 873,438,784 model scalars, or `0.0056274%`, below the lab's global changed-fraction cap `0.0002`. Maximum actual regional relative L2 was `0.0453202` for lap 2 and `0.0451707` for lap 3, below the unchanged `0.05` cap; BF16 rounding was included in those measured deltas. Their patched shard SHA-256 digests were `65b691e2658246a19ef19abe16bdac3dde59e2677565a783505803ec8e41075d` and `ab44e418b2252fe97e3fd68e05caab9c0ae42062bacfe58ca7bfce7c3cc96ced`. These are changes to stored norm weights, not a measured ±4.5% activation-gain change. No q/k norms, embeddings, projections or vision weights were edited.

Both patches were exploratory Codex-selected gain-calibration probes, not repairs to a diagnosed defective tensor. There was no training, gradient, loss optimization, targeted causal analysis or evidence that changing these norm vectors could teach Blender API details. Lap 2 changed output format but did not fix the API: it still selected `scene.objects[0]`, accessed nonexistent `.current_value`, reported each relative key as itself instead of `.relative_key.name`, and put an invented inventory in the response with ten `null` ranges despite observed 0–1 ranges. Lap 3 used a named lookup but repeated the invalid property and relative-key errors. Laps 1 and 3 were not valid outer JSON even after only removing terminal generation tokens. None safely handled missing mesh or shape-key datablocks. Completion markers recorded successful inference processes, not semantic validity. A pre-model runner path typo produced one process-failure marker and zero generation tokens; it was corrected before the single actual baseline and is not counted as a fourth inference.

All three failed this one inventory case. Response duration, syntactic format and a partial named-lookup improvement are not evidence of stage-05 competence. Both patches are rejected and not promoted. The accepted native rig and source checkpoint remain unchanged. Stage 05 still requires an actual source/native morph map, tested face and viseme controls, expression contact sheets, animator reset/keying evidence, retarget-scope record and embedded guide under the original human-reviewed workflow. Future model trials would need version-matched Blender API context, independent safe fixtures and held-out semantic evaluation; these runs do not establish a general deficiency or that a larger model is necessary.
