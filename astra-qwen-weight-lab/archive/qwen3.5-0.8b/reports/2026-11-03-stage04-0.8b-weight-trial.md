## Native Blender fallback status

Codex preserved the accepted stage03 input and inspected the imported rig in stock Blender. It has one armature with 879 bones, including 807 deform bones, 82 native constraints, and no Python drivers. The character has 90,865 vertices and 146 shape keys. Its existing leg IK has no pole targets and stretch enabled; the arms have no IK/FK switch controls. An isolated left-arm pilot added a nondeforming target and native IK with stretch disabled. Rest maximum vertex drift was `1.631e-05` Blender units; moving the target +0.3 Y changed vertices up to `0.6061`, and reset returned to the pilot rest state. This proves only that the isolated arm target affects the mesh while preserving its neutral state closely.

Pole placement remains unresolved. One experiment produced `0.04366` maximum vertex drift. A separate 120-fit sweep had best joint-matrix component error `0.01630`, above its `0.001` gate. These are different metrics and should not be compared as improvement. The [stage04 skill](../../skills/anime-blender-04-rig/SKILL.md) instructs: “Stop and restore the best draft after two consecutive experiments without measurable improvement; diagnose or escalate before another edit.” Codex stopped this pole approach and did not promote its private trial. Full controls, IK/FK switch fixtures, mirrored limb tests, renders, stock-Blender dependency proof, and human stage review remain open. The original workflow can continue only with those checks; stage04 has not passed.

Future model work should use version-matched official Blender API context, narrower independently verified fixtures, and held-out execution in a safe disposable scene before any specialization claim. Any training must follow the lab's provenance rules. These three runs do not establish that a larger model is necessary.
